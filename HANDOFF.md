# Handoff

## Ce qu'il me faut pour brancher la version finale

### 1. Firebase

Obligatoire pour enregistrer les reservations:

- `FIREBASE_PROJECT_ID`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY`

Optionnel pour plus tard:

- Firebase Hosting
- Firebase Analytics

### 2. Acces admin

Pour la page `/admin`:

- `ADMIN_ACCESS_TOKEN`

### 3. Coordonnees reelles

Les valeurs actuelles sont des placeholders. Il faut me donner:

- Numero de telephone
- Numero WhatsApp
- Adresse email
- Nom commercial final
- Logo, si vous en avez un

### 4. Regles metier a confirmer

- Horaires de service reels
- Zones desservies exactes autour de Sfax
- Tarifs finaux par forfait
- Types de voiture acceptes
- Delai moyen de confirmation apres reservation

### 5. Si vous voulez aller plus loin ensuite

- Paiement en ligne
- Authentification admin plus solide
- Notifications WhatsApp / SMS
- Carte / geolocalisation precise
- Tableau de bord avec filtres et changement de statut
